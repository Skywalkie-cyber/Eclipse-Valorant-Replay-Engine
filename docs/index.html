Engine Design

Engineered For Pure Performance

DirectX 11 DXGI Pipeline

Direct GPU VRAM frame grabbing using Microsoft DXGI Desktop Duplication. Eliminates system RAM bus transfers so your CPU stays 100% focused on game logic.

NVENC / AMF / QSV

Vanguard-Safe Log Tailer

Zero DLL injection and zero memory tampering. Kills and headshots are read from Valorant's sanctioned local disk logs via shared file read handles.

FILE_SHARE_ALL Read

Circular NVMe Spooler

Rolling 2-second segmented buffer slices keep video memory heap footprint tiny (<16MB RAM). Old footage is cleanly recycled on the fly.

Fast NVMe Ring Buffer

Ed25519 Minisign Updates

In-app updater verified by asymmetric cryptographic signatures. Only builds mathematically signed with the author's private key can ever execute.
