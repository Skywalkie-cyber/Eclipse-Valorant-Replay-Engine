Eclipse is a high-performance, strictly local replay buffer and highlight studio built specifically for competitive Valorant players. Powered by Direct3D11 DXGI hardware acceleration, Eclipse runs continuously in the background without dropping frames or adding input latency.

Press F8 at any moment to instantly capture your past 15 to 120 seconds of gameplay with pristine audio, synchronized killfeed telemetry, and interactive timeline markers.

Key Highlights:
⚡ Zero-Copy Hardware Buffer: Direct GPU framebuffer capture via DXGI Desktop Duplication with sub-1% CPU usage.
🎯 Automated Combat Telemetry: Visual timeline markers for headshots, multikills, and clutch rounds automatically synchronized using local game logs.
🛡️ 100% Vanguard & Riot ToS Compliant: Operates completely in user mode without DLL injection, memory hooks, or game file modifications.
🔒 Cryptographically Signed Direct Updates: In-app updater verified by Ed25519 public-key encryption so only authorized, developer-signed builds can ever install.
🗜️ Optimized Working Set: Smart segment spooling ensures RAM stays lean even during marathon gaming sessions.
